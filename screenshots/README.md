## Tips for Good Dashboard Screenshots
- Set your Power BI window to 1920×1080 before exporting
- Make sure slicers show "All" (no filters active) for overview shots
- Use Snipping Tool / macOS Screenshot for precise crops
- Aim for PNG format at ≥150 DPI for clear GitHub rendering
